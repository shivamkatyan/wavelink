Wavelink — Wi-Fi audio relay for a portable DAC. Source-available · free for personal use; commercial license required.

Honest gates: macOS Screen-Recording TCC, Windows WASAPI native check, Android device capture, iOS usbAudio/local-network, USB-DAC hotplug, Bluetooth lab, bit-perfect loopback, and store signing/notarization are pending external gates with runbooks — nothing here overclaims them. Android is a sideloadable signed dev build; macOS is an unsigned developer DMG.
