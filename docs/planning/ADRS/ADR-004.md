# ADR-004 Lossy Codec & Settings

Status: Accepted (2026-09-06)

## Context
Free Wi-Fi lossy mode; BT cells lossy; low latency suitable for music; legally distributable.

## Options
1. Opus (libopus via opus/opusic-sys, vendored BSD-3) — default candidate.
2. AAC (licensing/patent complexity), MP3 (patent+quality), Vorbis (quality/latency).
3. Native hardware AAC via OS (per-platform variance; no uniform control).

## Evidence
- Opus public xiph/libopus; no production pure-Rust Opus encoder (must wrap libopus) — verified 2026-09-06; fixed-point build for ARM Android.
- Opus algorithmic delay: 16.5 ms @10 ms frames / 26.5–28 ms @20 ms; good PLC.

## Decision
Opus 44.1/48 kHz, 20 ms frames (10 ms low-latency profile), ~128–256 kbps stereo VBR; TPDF dither + optional noise shaping when down-converting 24→16-bit; sources >48 kHz do not route through lossy (documented, FR-014).

## Consequences
Uniform quality across platforms; CPU cost on low-end phones bounded via complexity control; measurements recorded in ADR-005 benchmark harness.
## Reversal
Measured evidence (ADR-005/B0 bench) that another legally distributable codec beats Opus on quality/latency/CPU across targets.
