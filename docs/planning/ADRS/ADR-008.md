# ADR-008 Minimum Supported OS Versions

Status: Accepted (2026-09-06)

## Context
Need a defensible min-OS floor justified by API availability + support lifecycle for all shells.

## Options (from P0 evidence)
- Windows: 10 22H2 (EOL 2025-10-14; legacy) vs 11 (24H2 EOS 2026-10-13, 25H2 EOS 2027-10-12, 26H1 EOS 2028-03-14).
- macOS: 13 SCK (14.2+ per-process taps; Apple supports 14/15/26 currently).
- Linux: Ubuntu 22.04+/glibc≥2.35, PipeWire≥1.4 (CI-verified floor).
- Android: capture API needs API 29 (AudioPlaybackCapture); receiver OK 26/27; target 34+ for FGS + BIT_PERFECT.
- iOS: local-network TCC 14+; SCK emitter requires iOS 27 (ReplayKit 10+ covers older).

## Decision
Windows 11 24H2+ (Win10 22H2 documented as EOL-legacy/own-risk, not a supported floor);
macOS 13 (SCK; per-app taps feature-gated 14.2+);
Linux Ubuntu 22.04+/glibc≥2.35, PipeWire≥1.4;
Android minSdk 29 target 34+ (receiver-only shell minSdk 26 acceptable);
iOS 14 floor (SCK emitter path 27+, ReplayKit 12–26 fallback).

## Consequences
Broad modern coverage; clean lines for FGS/TCC/权限 behavior; per-version behavior tables in PLATFORM_MATRIX.
## Reversal
Support-lifecycle page changes (Microsoft/Apple/Google) or dependency bump requires higher floor.
